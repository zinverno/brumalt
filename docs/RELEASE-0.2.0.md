# Черновик релиза: Casual Memory Games 0.2.0 — первая бета

Шесть коротких игр для памяти и логики прямо поверх заметки Obsidian. Полностью бесплатно и офлайн, без аккаунтов и доступа к содержимому заметок.

В этой версии:

- Компактное окно вместо отдельной вкладки, возвращение к прежней заметке через Escape или крестик.
- «Числа», «Расположение», «Слова», «Последовательность» и новые «Правило», «Порядок».
- Сессии на 1/3/5 минут, отдельная адаптация и свободный выбор игры.
- Небольшая дневная цель и неделя участия без обязательных серий. Одно напоминание в день — только по желанию.
- Сохранены исправления записи и сложности 0.1.1; данные обеих прежних версий мигрируются.

Для установки распакуйте папку `casual-memory-games` из ZIP в `.obsidian/plugins/` отдельного тестового хранилища и включите плагин. Obsidian 1.7.2+. **При обновлении сохраните и предварительно скопируйте `data.json`; заменяйте только файлы плагина.**

Приложения к будущему релизу:

- `dist/casual-memory-games-0.2.0.zip`
- отдельно `dist/casual-memory-games/main.js`, `manifest.json`, `styles.css`
- `dist/SHA256SUMS`; лицензия MIT включена в ZIP.

Известные ограничения: очередь незаписанных результатов живёт только до выключения плагина/процесса; статистика ограничена 1000 попытками и 365 дневными записями. Синхронные изменения файла несколькими экземплярами приложения не поддерживаются. Уровни логических задач пока не проходили пользовательскую калибровку.

**Перед публикацией:** выполнить нативную и визуальную приёмку по `docs/VALIDATION.md`, получить три скриншота работающего плагина в пустом демонстрационном хранилище: главная, логическая игра, прогресс. В текущей среде запуск Obsidian и Chromium блокируется до загрузки плагина, поэтому нативная/мобильная совместимость и внешний вид не объявляются проверенными. Скриншоты-макеты не подготовлены.

Этот файл — только локальный черновик. Репозиторий, публичный релиз и заявка в каталог Obsidian не опубликованы.
