# Скриншоты Brumalt для статьи — ожидают съёмки

Изображения пока не созданы: запуск настоящего Obsidian заблокирован текущим окружением. Ниже — план файлов и подписей, а не утверждение о наличии снимков. Инструкция: [нативная съёмка](../../../docs/SHOWCASE.md).

Все будущие снимки должны показывать настоящий Obsidian в отдельном хранилище `Brumalt Showcase`. Статистика будет синтетической: это демонстрация интерфейса, а не результаты исследования или реального человека.

| Файл | Что показывает | Место в статье | Предлагаемая подпись |
| --- | --- | --- | --- |
| `01-home.png` | Главное окно, шесть игр, длительность и дневная цель | После знакомства с продуктом | «Brumalt: короткая сессия или отдельная игра поверх заметки». |
| `02-memory.png` | «Расположение» на этапе запоминания; предметы в сетке | Раздел об играх на память | «Запомните расположение предметов, затем найдите нужный». |
| `03-logic.png` | «Правило»: примеры преобразования и варианты ответа | Раздел о логических играх | «Определите преобразование по примерам и выберите результат». |
| `04-progress.png` | Дневные баллы, неделя, диаграмма и результаты | Раздел о статистике и спокойном ритме | «Игровой профиль и регулярность — на синтетических демонстрационных данных». |
| `05-settings.png` | Русские настройки: язык, цель, напоминания, доступные игры | Раздел о настройке и локальной работе | «Язык, необязательная дневная цель и доступные игры настраиваются в Obsidian». |

Планируемый размер первых четырёх файлов — 1600 × 900; настроек — 1600 × 1100, чтобы уместить список игр без дорисовки. Окончательную читаемость необходимо проверить на самих изображениях.

После съёмки заменить статус «ожидают съёмки» на фактическую дату и версию Obsidian, сохранить сведения о синтетических данных. Только после визуальной проверки собрать `dist/brumalt-habr-screenshots.zip` командой `node scripts/showcase.mjs pack`. Архив предназначен для статьи, не для установки плагина и не для GitHub Release Assets.
